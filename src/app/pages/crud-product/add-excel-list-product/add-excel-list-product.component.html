Carga de Excel de Productos

1. Requisitos Previos

  • Un archivo Excel con las siguientes columnas: codigo,descripcion,nombre,iva,precio Lista,utilidad-ganancia .
  • Respetar el orden de las COLUMNAS.
  • Acceso al sistema con permisos para cargar productos.

2. Procedimiento

Paso 1: Seleccionar el archivo Excel

Paso 2: Elegir el proveedor

Selecciona el proveedor correspondiente desde el combo box desplegable.


Seleccionar Proveedor Selecciona un proveedor {{item.id}} - {{ item.name }}

Paso 3: Enviar el archivo

Una vez seleccionado el archivo y el proveedor, presiona el botón “Subir Archivo”. El sistema validará el formato del archivo.

Paso 4: Confirmar la carga

Si el archivo es válido, se mostrará un mensaje de confirmación y los productos se registrarán en la base de datos.

3. Posibles Errores y Soluciones

  • Error: “Formato de archivo incorrecto” → Asegúrate de que el archivo sea un Excel (.xlsx) con las columnas correctas.
  • Error: “Proveedor no seleccionado” → Selecciona un proveedor antes de subir el archivo.
  • Error: “Datos incompletos” → Revisa que todas las filas contengan los datos necesarios.
